# 从请求到可复现图件

新任务先使用[按图型提示词](../references/prompt-routing.md)：读取共同模板，再组合实际图型补充。八类模板均为中英双语；它们帮助填写科学约束、检索需求和Figure Brief，不改变下述严格CSV接口，也不自动执行结构绘制、照片编辑或FE求解。

1. 明确读者要理解的问题。教学 spring 示例比较两条自定义线性关系，单位为 mm、N，不赋予实验含义。
2. 打开 CSV 核对列名、数据点数量和单位，填写 JSON 的 provenance、reader_question、claim、must_keep。复制模板后逐项重写来源、公式、单位与必须保留项，不能沿用与新数据不符的教学公式。程序只能检查声明的结构，不能验证其真实性。将修改请求落实为 allowed_style_changes 和 style。
3. 运行 README 中 check。输入检查通过后执行 render 到全新目录。程序记录输入哈希，保留源文件字节及点序。
4. 运行 verify。它重新解析 SVG 的数据顶点、裁剪区和参考位置、PDF 页面与嵌入字体、PNG 像素与 DPI/物理尺寸，并比对必需文件清单和哈希。失败后 verification.json 会变成 FAIL，不能继续引用旧 PASS。
5. 打开最终尺寸和灰度图。SVG 文字及曲线路径可用矢量编辑器调整。调整后 verify 会报告文件变化，应另存版本并重新核查，避免把手改图当成原脚本输出。
6. 根据任务单请作者确认科学问题、标注及单位。自动报告的人审状态为 PENDING，作者签署的审阅记录另外保存，不篡改程序检查结果。
7. 交付整个输出文件夹。收件人按 REPRODUCE.md，在同一 Python 次版本的独立环境安装 requirements.txt，用输出中的 figure.py 和 brief.json 重跑。清单记录传递依赖，任务单中的 font_sha256 核对字体。默认字体来自锁定 Matplotlib；中文等自定义字体需另行合法安装，不能去掉字体指纹后宣称同等复现。跨系统字体及库版本可能影响布局，重新进行数值、尺寸和视觉核查。

## 异常示例

删除 unit 会报告缺失字段，CSV 中填入 NA 会报告所在行列，空字符串会报告缺失值。请求 xlim 截掉峰值会被拒绝。非单调横坐标会给出警告并保持输入顺序。修改 source.csv 或 figure.svg 后运行 verify 会失败。

JSON 格式错误、重复键、NaN/Infinity、错误类型或未知字段均停止。CSV 空文件、仅表头、少于两点、重复表头、空白记录和参差行均停止。极端值超出渲染器保守范围或小数折叠为相同浮点数时停止，不能自行补数、改单位或重采样。尺寸/DPI组合超过40MP也停止。`check`通过仅代表输入结构与数值可接受；缺字体、缺字形、低对比和布局问题在`render`检测。长标签可人工明确换行，增大画布或调整字体必须得到任务单的样式授权。

## 安装资源与独立重跑

安装后使用虚拟环境里的Python执行 `<skill目录>/scripts/figure.py render <skill目录>/assets/brief-template.json --out <全新目录>`。此例只依赖安装目录的模板、CSV、脚本和锁文件。依赖不随skill复制，必须先按安装目录的requirements-lock.txt装入环境。已有skill和输出都会拒绝覆盖，保留旧版本后另行安装或生成新目录。

公开当前版本实例在 examples/expected-v0.1.3/spring、decay 与 independent；independent 为0.1.2构造的十点三曲线诊断数据，本版复用重跑。历史结果原样保留在本地，发布包只选入当前版本实例。自0.1.1起的严格核查不承诺接受更旧清单；使用旧输入在新目录重新渲染，不修改历史记录。

## 从现有图开始

先记录原图中的坐标范围、字体、线宽、图例位置和边界含义，并回到授权数据。原图只能辅助视觉诊断。任务单明确哪些样式可改，数据处理 method 保持 none。缺失数据或单位时先补齐来源，避免从外观推断科学事实。
