# 0.2.1-local 复测修复

修复0.2.0-local在损坏/过期索引下仍返回案例、预览改动仍显示已审阅、错误嵌套类型触发Traceback的问题。索引schema 2绑定配置与元数据哈希，检索前全量重算实际文件哈希；缺失索引拒绝验证。旧索引需先审核修改，再运行index --deep重建。该命令可以恢复派生缓存，不改原件和卡片。
