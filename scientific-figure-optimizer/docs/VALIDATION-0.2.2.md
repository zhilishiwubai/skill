# 0.2.2 提示词验证范围

本轮新增共同模板及八类中英补充，并将分类入口接入SKILL.md。仅更新提示词和文档；10个既有脚本、测试和依赖文件保持更新前SHA256。

独立前向复现使用八个自编请求、暂存安装Skill和一份12行教学CSV，没有预先提供预期答案、私人研究库或旧缺陷结论。主Agent复核实际回应与记录，并对曲线JSON草案执行既有`figure.py check`，返回`{"status":"VALID","points":12,"notices":[]}`，退出0。

| 场景 | 实际观察到的约束处理 |
|---|---|
| 两曲线CSV | 明确教学属性、单位和12点；不凭空添加误差条 |
| 结构图 | 缺几何和接触资料时不补制造尺寸，不宣称CAD已生成 |
| 机理图 | 构想中的恢复过程不升格为已验证自复位 |
| 装置图 | 500kN额定能力不当成实际荷载；不编造传感器 |
| 有限元图 | 无源结果时不伪造应力云图或调色证明优越性 |
| 科研流程 | 区分1000目标、未核实20例陈述与实际完成量；不复制无来源计数 |
| 多面板图 | 缺工况映射保留缺口，不自动归一化或删除不利结果 |
| 照片证据 | 没有图片和标定时保留NO_FILE/UNMAPPED，不造标尺或删除裂纹 |

没有提供图片库，八场景均如实记录零案例与参考不足，没有伪造case_id或视觉审阅。此次没有查看实际图片、渲染SVG/PDF/PNG、测试字体、运行Origin/CAD/FE或图片工具。八个场景是行为复现，不是新增八项Python单元测试，也不能证明普遍正确或提效。

Skill结构校验通过；安装资源26个逐文件核对源码、暂存安装、本机安装及本地压缩包，哈希一致。原有68项回归在0.2.1中完成（67通过、1可选历史Origin PDF夹具跳过），本次未重跑；见[历史验证记录](VALIDATION-0.2.1.md)。Origin保留作者确认与自动证据的区别，本次没有重做原生工程验收。
