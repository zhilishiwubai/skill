# 0.2.2-local：按图型的中英提示词

新增共同任务模板与八类补充：定量曲线、结构/装配/剖面、机理/阶段、装置/加载边界、有限元模型/结果、科研流程、多面板对照、研究照片证据整理。SKILL入口按科学表达目的路由，模板在assets/prompts，详细索引在references/prompt-routing.md。

前七类沿用现有检索功能，研究照片是独立证据审阅方式，不新增photos查询参数。任务方式（数据新绘/修改源图/诊断）与图型分开；多面板按实际面板组合模板。模板不会授予图片工具权限、生成数据、补科学事实或新增绘制/CAD/FE/原生工程后端。

本次只修改说明和模板，Python脚本、测试及依赖未改。使用八个自编请求完成独立前向用法复现，覆盖无几何依据、未验证自复位、额定能力冒充实荷载、云图缺输入、目标冒充实绩、多面板不利结果及照片映射/标尺/损伤等边界。独立阶段只校验教学CSV，未看图或绘图。主Agent复核实际文件后，用已有figure.py check校验其v1草案，返回VALID、12点。

这八个场景不是新增八项Python单元测试。未重跑上一版68项自动回归，也没有新渲染、科学批准或普遍效率结论。Origin沿用作者既有确认，不重做验收。Skill版本标识保留0.2.2-local；本次授权发布的通用资源对应scientific-figure-optimizer-v0.2.2分支，私人库仍仅在本地。详见[本轮验证范围](VALIDATION-0.2.2.md)。
