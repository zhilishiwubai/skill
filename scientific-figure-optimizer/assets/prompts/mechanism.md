# 机理与工作阶段 / Mechanisms and working stages

与[共同模板](common.md)组合。检索功能：`mechanism`；当前主要交付机理表达方案。

## 中文

```text
图型补充：机理/阶段图。过程范围：[加载、滑移、卸载、恢复或其他有依据的过程]。
列出各状态的依据、进入/退出条件及比较量，区分已观测现象、模型假设和作者构想。阶段边界必须来自明确记录；依据不足时标待确认，不把参考示意的阶段直接移植到本试件。

布局采用清楚的起点、状态变化和终点，必要时分开加载与卸载路径。统一同一部件的方向、尺度约定和编码，说明箭头表示载荷、位移、流向、能量传递还是逻辑关系。未经依据支持，不用箭头构造因果，也不添加裂纹、接触脱开或塑性区。

严格区分弹性储能、摩擦/塑性耗散和外部功；没有数据与能量平衡依据时只做定性示意，不给百分比或数值。自复位、恢复和循环可逆性需各自证据，不能从弹簧图标推断。若存在回程，标清返回条件；无回程依据不画自动恢复闭环。

交付状态表、证据/假设标记、面板顺序、箭头语义、部件/能量编码、图注及需要作者确认的科学问题。当前先形成Figure Brief；原生工程、仿真结果或生成图片不从提示词自动获得。
```

## English

```text
Figure supplement: mechanism/stage diagram. Scope: [loading, sliding, unloading, recovery or another supported process].
List the evidence, entry/exit conditions and comparison variables for each state. Separate observations, model assumptions and proposed concepts. Stage boundaries require records; uncertain boundaries remain pending rather than being transferred from a reference schematic.

Show a clear start, transitions and end, separating loading/unloading paths when needed. Keep component orientation, scale conventions and encoding consistent. Define whether each arrow represents load, displacement, flow, energy transfer or logic. Do not invent causality, cracks, separation or plastic zones.

Distinguish elastic storage, frictional/plastic dissipation and external work. Without data and an energy-balance basis, use qualitative representation without percentages or values. Self-resetting, recovery and cyclic reversibility each require evidence; a spring icon proves none of them. Mark return conditions only when a return path is supported.

Deliver a state/evidence table, assumption labels, reading order, arrow meanings, component/energy encoding, caption and author questions. The current route prepares a Figure Brief; prompts alone do not produce native projects, simulation results or generated images.
```
