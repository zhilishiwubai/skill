# 科研流程与技术路线 / Research workflows and methods

与[共同模板](common.md)组合。检索功能：`workflow`；PPT排版属于演示文稿工具。

## 中文

```text
图型补充：研究流程/技术路线。输入：[实际步骤、计划、输入输出、依赖和已有执行记录]。
先分清已完成、正在做和计划工作；节点和数量从实际资料核对。建设报告、目标1000例、筛选计划或模板数不能写成已完成成果；不复制参考论文的样本、筛选或统计数量。

以研究问题为主线，明确每个节点的输入、操作、输出和进入下一步的条件。顺序、并行、依赖、决策和返工分别用清楚的连接语义，避免把相邻步骤误画为科学因果。决策分支标条件，回路给返回位置和停止条件；无依据不添加自动闭环。

采用简短节点文字、统一层级与阅读方向，控制交叉箭头；必要时把主流程和阶段内细节分开。颜色可编码任务类别或完成状态，但同一图不能混用两种意义；状态还需文字/线型支持灰度阅读。图例说明计划与实绩，不能用完成勾选图标替代执行证据。

交付步骤/依赖表、完成状态来源、节点文案、布局、箭头/颜色语义和Figure Brief。没有实际绘制接口时只制定方案；提示词不会制作PPT或完整网页，也不把运行时参考说成训练。
```

## English

```text
Figure supplement: research workflow/method roadmap. Inputs: [actual steps, plans, inputs/outputs, dependencies and execution records].
Separate completed, ongoing and planned work. Verify nodes and counts from records. A construction report, a 1000-case target, a screening plan or template count is not a completed result; do not copy another paper's sample/screening/statistical counts.

Organize around the research question. Define each node's input, operation, output and transition condition. Distinguish sequence, parallel work, dependency, decisions and rework; adjacency is not scientific causality. Label decision conditions and give loops a return point and stopping condition. Do not invent an automatic closed loop.

Use short labels, consistent hierarchy/direction and few crossing connectors. Separate overview from stage details when useful. Color may encode task class or completion status, but not both ambiguously; add text/line cues for grayscale. A checkmark cannot replace execution evidence.

Deliver a step/dependency table, status provenance, node wording, layout, arrow/color semantics and Figure Brief. Without a drawing interface, stop at planning. This prompt does not create a PPT/web system or turn runtime reference into model training.
```
