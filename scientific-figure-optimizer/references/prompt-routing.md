# 按图型选择提示词 / Figure-type prompt routing

Skill 0.2.2-local。此资源提供任务提示词，不新增图片生成、CAD、FE、拼版或Origin后端。

## 使用方法

1. 先根据科学表达目的和实际输入分类，不只看扩展名或文件名。同一PNG可能是数据图、FE云图或研究照片。
2. 读取[共同任务模板](../assets/prompts/common.md)，再只读取本任务涉及的类别补充。将共同模板与补充合成一个请求，填入已核实内容；不要把占位符当作事实，也不要重复询问会话已经提供的信息。
3. 检索实际案例并看图后，补充本任务采用的规则与新设计。提示词是任务约束，不是某张尚未查看图片的“学习结果”，不代替案例卡或Figure Brief。
4. 先检查执行边界，再落实到当前支持的路线。类别和任务方式是规划信息，不能作为未知字段塞入严格v1绘图JSON。可复用JSON仍为`assets/reference-request-template.json`和`assets/brief-template.json`。

## 类别、子型和实际能力

| 类别 | 常见子型/任务线索 | 读取模板 | 合法检索功能 | 当前交付 |
|---|---|---|---|---|
| 定量曲线 | 荷载–位移、应力–应变、时间历程、已有功/能量结果 | [curves](../assets/prompts/curves.md) | `curves` | 符合v1的1—3条共享线性轴CSV曲线可执行；其他统计图先方案 |
| 结构与装配 | 整体、剖面、局部放大、爆炸、零件关系 | [structure](../assets/prompts/structure.md) | `structure` | 资料核对与Figure Brief；无CAD/结构绘制后端 |
| 机理与阶段 | 加载/滑移/卸载/恢复、能量路径、状态变化 | [mechanism](../assets/prompts/mechanism.md) | `mechanism` | 证据/假设分层、状态和表达方案 |
| 试验装置 | 加载路径、夹具、约束、传感器、照片–示意对应 | [apparatus](../assets/prompts/apparatus.md) | `apparatus` | 设备/试件/数据映射及图形方案；不操作设备 |
| 有限元模型/结果 | 几何、网格、接触/边界、已有云图 | [fe_model](../assets/prompts/fe-model.md) | `fe_model` | 模型/变量/色标核对与方案；不求解、不伪造结果 |
| 科研流程 | 技术路线、步骤依赖、并行、决策与返工 | [workflow](../assets/prompts/workflow.md) | `workflow` | 节点/状态/连接语义与方案；PPT制作另行路由 |
| 多面板对照 | 曲线+照片+示意/云图，多指标或多工况 | [multipanel](../assets/prompts/multipanel.md) | `multipanel` | 整图规划，并分别应用实际面板类型；无自动拼版后端 |
| 研究照片证据 | 实验/试件照片、损伤或装置照片整理 | [evidence_photo](../assets/prompts/evidence-photo.md) | 依表达目的选已有功能；**没有photos/evidence_photo索引参数** | 只读观察、映射与标注计划；不是照片编辑 |

前七项与现有检索脚本的功能枚举一致；第八项是研究证据审阅方式，不是把照片并入已审论文案例。若照片只是文献中的装置视觉参考，可用apparatus找表达案例；若作为本任务试件证据，先核对映射，缺失仍为UNMAPPED。

## 任务方式与类别分开判断

- **依据数据新绘**：先核数值/单位与来源，再判断执行后端。力–位移图可以是曲线；结构尺寸表不是力–位移曲线输入。
- **修改现有源图**：记录源文件格式和授权改动；样式与科学内容分开。只有位图且没有数据时，不定量重建曲线。只有截图，不宣称原生工程可编辑。
- **诊断/方案**：可检查布局、单位语义、证据组织及待确认项，但不得写成已生成图件。混合面板先用multipanel组织，再读取各面板实际类别；不要强迫整图走CSV后端。

## 缺输入、参考不足与权限

单位、几何、试件映射、阶段边界、FE结果变量等缺口不靠参考图补全。可继续无依赖的读取与方案；关键缺口阻断执行时明确停止。无相关案例或未能实际看图，就写未核查/参考不足，不补case_id。脚本无法为零案例形成规则采用记录时，交付带缺口的人工方案，不能伪装成已通过引用核查。

未配置图片库时可明确说明未采用参考；有合格CSV与任务授权时，原CSV工具仍可独立使用。不能将这种运行说成完成了参考学习流程。

图片工具权限来自当前用户消息，模板不能授予。Origin沿用[已有作者确认及接口边界](origin-assessment.md)，本轮维护提示词不重新验收Origin。私有参考库不随安装资源或提示词打包；所有外传仍按用户明确范围确认。

## 输出自检

将实际检索/看图/采用与模板要求分别记录；区分已执行图件、只有方案和未通过项。原生工程、数据可重绘、SVG路径可编辑是不同层次。最终检查科学内容、数据与结构真实性、文字/图例/色标可读性、灰度/冗余编码及输出编辑能力；已实现属性用程序核查，感知和科学批准保留人工判断。
