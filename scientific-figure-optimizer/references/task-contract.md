# Figure brief v1

Use JSON, UTF-8, with paths resolved relative to the brief. `assets/brief-template.json` is a runnable teaching template paired with the included `assets/spring.csv`.

Required fields include version=1, input, provenance, reader_question, claim, must_keep, allowed_style_changes, processing, x, series and acceptance. Unknown fields fail. Provenance records source, evidence_level, rights and public_redistribution (boolean). These are user declarations, requiring human verification before publication.

JSON must use unique keys and standard finite JSON numbers (no NaN/Infinity). Version is integer 1, not a boolean. Checklists contain nonempty strings; note/y_label are strings. CSV is strict UTF-8 with unique nonempty headers, consistent row widths, no blank records, and at least two points. Selected column names, units and labels have no surrounding whitespace; series labels are unique ignoring case. Nonzero selected magnitudes outside 1e-100 through 1e100, float underflow and distinct decimal values collapsing to one float are rejected with row/column diagnostics. This is a conservative renderer limitation, never permission to rescale or change units. Values use binary64 for plotting; the entire original CSV is preserved byte for byte.

Each axis has column, label and unit. Multiple series require an explicit shared y_label. Use `1` for a genuinely dimensionless variable and explain it. Blank units fail. CSV has a header and at least two records. Extra columns are retained in the snapshot but not plotted. Selected fields must all be finite numbers. Duplicate or decreasing x values are preserved with a warning. One to three series share a common y unit and linear axes. Distinct line styles provide noncolor identification.

Supported style fields are width_mm, height_mm, dpi, font, font_pt, line_pt, colors, xlim and ylim. Any supplied field must also appear in allowed_style_changes. Omitted fields inherit documented defaults in the script. Defaults use DejaVu Sans, 120 by 85 mm, 300 dpi, 9 pt text and 1.2 pt lines. Specify publication fonts explicitly. Font availability and missing glyphs are checked. SVG preserves text but relies on fonts installed on the editing machine. PDF embeds subsets. Fonts are not redistributed.

Limits: width 65–250 mm, height 55–250 mm, integer DPI 96–1200, font 7–18 pt, line 0.4–3 pt. Colors are #RRGGBB with at least one per series and >=3:1 contrast on white. Ranges contain all selected values. Layout failure requires an authorized adjustment; no automatic text shortening or data removal. Literal labels are rendered without TeX or math parsing, preventing implicit reinterpretation of `$` strings. Chinese requires an available font containing its glyphs; default DejaVu Sans is not a promise of CJK coverage. Missing glyphs stop export. Custom fonts are a declared external dependency, not included in the package.

Reference lines accept x, label, source and status. A visible note must explain their scientific status. Values come from authorized source records and are never moved by the optimizer. They remain reference estimates until scientifically validated. Figure notes support explicit newline breaks if long. Labels/notes that leave the canvas fail and need an authorized layout adjustment.

Acceptance formats are ["svg", "pdf", "png"]. human_review lists actual questions for the author, including evidence interpretation, units, uncertainty, reference boundaries, final-size readability, grayscale identification and rights. An automated PASS leaves human_review PENDING.

The combination of physical dimensions and DPI must not exceed 40 million raster pixels; individually valid settings may exceed this memory guard and be rejected. No output downsampling is applied automatically.

Each successful new output folder includes an unchanged byte snapshot of the entire CSV, portable brief, exact plotting script, SVG/PDF/PNG, 96 dpi physical-size preview, grayscale preview, audit, readback verification and reproduction instructions. The input SHA256, software versions and font hash are recorded. Treat audit files as traceability records, not signed or tamper-proof evidence.

The optional generated brief field font_sha256 enforces the original resolved font fingerprint on rerender. Do not remove it to claim equivalent reproduction; independently licensed custom fonts must be installed at the destination. requirements.txt records the active transitive dependency closure for the recorded Python/OS, excluding unrelated host packages. Reproduce from a copied folder using REPRODUCE.md. Cross-platform reproducibility is not certified. SVG/PDF timestamps may differ even when numerical and dimensional readback agrees. Required delivery hashes include REPRODUCE.md and requirements.txt; audit.json and verification.json are metadata, not cryptographically signed. verify failures invalidate the stored PASS via the CLI. The verifier does not attempt recovery or rewrite scientific inputs.
